# Electric Vehicle Market Performance & Insights

## Project Overview
This Tableau capstone project explores electric vehicle (EV) population data to understand manufacturer distribution, electric driving range, and the share of different EV types.

## Objectives
- Analyze EV counts by manufacturer.
- Compare average electric range across manufacturers.
- Understand the distribution of Battery Electric Vehicles (BEVs) and Plug-in Hybrid Electric Vehicles (PHEVs).
- Present key findings through an interactive Tableau dashboard.

https://data.wa.gov/Transportation/Electric-Vehicle-Population-Data/f6w7-q2d2

The dataset contains information about electric vehicles, including manufacturer, vehicle type, and electric range.
